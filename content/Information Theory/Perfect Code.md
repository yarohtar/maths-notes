An $[n,m]$ [[Information Theory/Binary Code]] which is $e$-[[Information Theory/Error correcting]] is called perfect if it satisfies the [[Information Theory/Hamming's Bound]]
$$
m= \frac{2^{n}}{V(n,e)}
$$
If $\frac{2^{n}}{V(n,e)}$ is not an integer then no perfect $e$-[[Information Theory/Error correcting]] code of length $n$ exists
