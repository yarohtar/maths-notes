Let $(E,\mathcal{E})$ and $(G,\mathcal{G})$ be [[Analysis/Measure/Measure\|measurable spaces]]. 
A function $f:E\to G$ is measurable if $f^{-1}(A)\in \mathcal{E}$ for all $A\in \mathcal{G}$.

In the case $(G,\mathcal{G})=(\mathbb{R},\mathcal{B})$ ([[Analysis/Measure/Borel Sigma Algebra]]) 
we simply call $f$ measurable on $E$.
