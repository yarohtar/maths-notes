A graph is an ordered pair $G=(V,E)$ of sets $V$ and $E$
where $E\subseteq \mathcal{P}V$ and $e\in E\implies \lvert e \rvert=2$.
The set $V$ is called the set of vertices.
The set $E$ is called the set of edges.
