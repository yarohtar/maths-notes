Let $m,k,d\in \mathbb{N}$.
Then there is some $n\in \mathbb{N}$ 
such that whenever $[m]^{n}$ is $k$-coloured,
there exists a monochromatic $d$-[[Combinatorics/Ramsey/Parameter Set]].
### Proof
Let $n'=HJ(m^{d},k)$.
By [[Combinatorics/Ramsey/The Hales-Jewett Theorem]], find a [[Combinatorics/Ramsey/Combinatorial Line]] in $[m^{d}]^{n'}$.
This is now a $d$-[[Combinatorics/Ramsey/Parameter Set]] in $[m]^{dn'}$, so set $n=dHJ(m^{d},k)$.
