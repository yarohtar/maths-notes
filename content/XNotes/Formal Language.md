Given a set of symbols $\Sigma$, the set of all strings is $\mathbb{W}=\Sigma ^{*}$, also called the set of words.

A formal language is any subset $L\subseteq \mathbb{W}$.

[[XNotes/Operations on Formal Languages]]

### Definition
If $G$ is a [[XNotes/Grammar]] and $\mathcal{D}(G,S)$ is the set of all [[Foundations/Derivable Strings]] from $G$, then $\mathcal{L}(G)=\mathcal{D}(G,S)\cap \mathbb{W}$ is a [[XNotes/Formal Language]] derived by $G$.
