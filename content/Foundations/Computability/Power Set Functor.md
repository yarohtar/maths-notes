The [[Foundations/Category Theory/Covariant]] power set functor $A\to PA$ is a [[Foundations/Category Theory/Functor]] $\mathrm{Set}\to \mathrm{Set}$ [[Foundations/Category Theory/Category of Sets]]
Given $A\xrightarrow{f}B$ 
we define $Pf:PA\to PB$ by $Pf(A')=\{ f(a):a\in A' \}\subseteq B$

We also have the [[Foundations/Category Theory/Contravariant]] powerset functor:
$P^{*}:\mathrm{Set}\to \mathrm{Set}^{op}$ (or $\mathrm{Set}^{op}\to \mathrm{Set}$)
defined by $P^{*}A=PA$ 
and given $A\xrightarrow{f}B$ we have $P^{*}f(B')=\{ a\in A:f(a)\in B' \}$
