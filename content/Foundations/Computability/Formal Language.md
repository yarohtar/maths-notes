Given a set of symbols $\Sigma$, the set of all strings is $\mathbb{W}=\Sigma ^{*}$, 
also called the set of words.

A formal language is any subset $L\subseteq \mathbb{W}$.

[[Foundations/Computability/Operations on Formal Languages]]

### Definition
If $G$ is a [[Foundations/Computability/Grammar]] and $\mathcal{D}(G,S)$ is the set of all [[Foundations/Computability/Derivable Strings]] from $G$,
then $\mathcal{L}(G)=\mathcal{D}(G,S)\cap \mathbb{W}$ is a [[Foundations/Computability/Formal Language]] derived by $G$.
