A [[Foundations/Computability/Partial Function]] $f:\mathbb{B}^{k}\dashrightarrow \mathbb{B}$ is called computable if there is a register machine $M$ such that $f=f_{M,k}$. 

We say that a [[Foundations/Computability/Partial Numerical Function]] $f$ is computable if and only if its encoding is computable.

A set $X$ is computable if its [[Foundations/Computability/Characteristic Function]] is computable. 
This works both for $X\subseteq \mathbb{B}^{k}$ and $X\subseteq \mathbb{N}^{k}$.

### Proposition
The class of [[Foundations/Computability/Computable\|computable]] [[Foundations/Computability/Formal Language]]s is closed under union, intersection, complement, and concatenation.
