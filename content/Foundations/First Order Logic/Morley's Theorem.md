Let $T$ be a [[Foundations/First Order Logic/Complete Theory]] in a countable [[Foundations/First Order Logic/Language]].
If $T$ is $\kappa$-[[Foundations/First Order Logic/Categorical]] for some $\kappa>\aleph_{0}$,
then it is $\kappa$-[[Foundations/First Order Logic/Categorical]] for all $\kappa>\aleph_{0}$.
